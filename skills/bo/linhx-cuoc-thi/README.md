# linhx-cuoc-thi (v0.1)

Plugin Claude Code: radar cuộc thi sáng tạo, viết lách, giải thưởng tại Việt Nam cho thương hiệu cá nhân.

| Skill | Khi nào |
|---|---|
| `radar-cuoc-thi` | "có cuộc thi nào", quét định kỳ, ra digest + lịch |
| `tham-dinh-cuoc-thi` | gửi link thể lệ, hỏi nên làm không |
| `viet-bai-du-thi` | viết bài đúng thể lệ, phản biện theo tiêu chí |
| `theo-doi-ket-qua` | dò kết quả, sổ giải, khai thác branding |

Script `scripts/contestscan.py` (Python chuẩn) chạy trong thư mục radar có `config/`, `data/`, `output/` (đặt `RADAR_HOME`). Không skill nào nộp bài, đăng ký hay đăng bài thay người dùng.
