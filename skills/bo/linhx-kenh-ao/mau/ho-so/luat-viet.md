# Luật viết

Chỉ số chính: luật mới chỉ thêm từ lần Linh sửa bài (reflection kiểu LangChain) hoặc từ RETRO có tín hiệu đủ mạnh · mỗi luật một dòng, có phiên bản.

Agent đọc toàn bộ file này trước mỗi lần viết bài. CLI `luat-viet` nối thêm dòng ở cuối.

```json
{"ghi_chu": "luật nằm ở danh sách bên dưới, khối json này chỉ để file hợp lệ"}
```

- v0: Mở bài bằng một cảnh cụ thể trong ngày, không mở bằng câu hỏi chung chung.
