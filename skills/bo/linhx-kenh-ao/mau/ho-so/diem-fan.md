# Điểm fan

Chỉ số chính: giảm **0,9** mỗi tuần · bậc: người lạ < 1 ≤ tương tác < 6 ≤ quen < 15 ≤ fan < 40 ≤ siêu fan.

Điểm fan đo người khác gắn với kênh mình (chiều vào). Điểm tin trong `hanh-vi.md` đo quan hệ hai chiều với người mình chủ động đọc và kết thân (chiều ra).

```json
{
 "su_kien": {"binh_luan": 3, "dm": 5, "chia_se": 4, "quay_lai": 2},
 "giam_moi_tuan": 0.9,
 "bac": [["sieu_fan", 40], ["fan", 15], ["quen", 6], ["tuong_tac", 1], ["nguoi_la", 0]]
}
```
