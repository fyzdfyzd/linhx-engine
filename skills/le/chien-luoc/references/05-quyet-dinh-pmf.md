# 05 · Quyết định sản phẩm hoặc thông điệp

Rút từ `PMF_STRATEGY_..._guided` (3 chân dung trọng điểm), `DANH_GIA_2_PHUONG_AN_PMF` (phương án AI và phương án chị Hương), `02_BRAND_STRATEGY` Kim Gia Bảo Gift (CVP, USP, UVP).

## 1. Thứ tự trong file QUYET-DINH

1. **Tóm tắt điều hành** (1 trang, đứng một mình được): chọn ai, bán gì, vì sao thắng, cần lãnh đạo quyết gì.
2. Ba chân dung trọng điểm và vai trò (ví dụ: tạo số lượng lặp lại · nâng đỉnh thương hiệu · tạo sóng mạng xã hội).
3. PMF cho từng chân dung.
4. CVP · USP · UVP cho từng dòng sản phẩm.
5. Thông điệp theo tầng.
6. 2–3 phương án, chấm 12 tiêu chí, phương án lai.
7. Lộ trình và cổng Go/No-Go.

## 2. PMF cho một chân dung (bảng)

`Mục tiêu: <một câu>`

| Yếu tố | Mình khớp nhu cầu thế nào |
|---|---|
| Sản phẩm | tên bộ sưu tập, món cụ thể |
| Giá | cơ chế (ví dụ giá cố định theo bộ thay vì theo gram), mức giá cụ thể |
| Trải nghiệm mua | không gian, nghi thức, giấy chứng nhận |
| Bằng chứng tin cậy | chứng thư, nghệ nhân, bảo tàng |
| Kênh | nơi bán, nơi không bán |
| Bao bì / khuyến mãi | |
| Truyền thông | kênh, kiểu KOL, hashtag |

## 3. CVP · USP · UVP (mẫu KGBG)

- **CVP**, tuyên ngôn giá trị cho khách, tách **lý tính** và **cảm tính**.
- **USP**, lợi thế bán hàng độc bản: 2–4 điểm cụ thể, sờ được (bao bì, công nghệ, nghi thức).
- **UVP**, giá trị độc nhất định vị: **một câu in đậm**, có thể kiểm được ("sản phẩm quà tặng duy nhất càng để lâu càng tăng giá, mua lại đúng giá vàng ngày").

## 4. Thông điệp theo tầng

```
Ý LỚN (1 câu)
├── Trụ cột 1 ── bằng chứng 1a [BC], 1b [BC]
├── Trụ cột 2 ── bằng chứng ...
└── Trụ cột 3 ── bằng chứng ...
```
Mỗi chân dung có thể có lời chào riêng, nhưng phải quy về cùng ý lớn.

## 5. So các phương án: 12 tiêu chí chiến lược

Luôn có ≥2 phương án khác nhau thật. **Nếu khách có phương án riêng, đặt ngang hàng và chấm cùng thước** (bài học Trân Bảo: phương án chị Hương thua 46/49 nhưng có giá trị riêng, cuối cùng ghép lai).

| # | Tiêu chí | PA-A | PA-B | Ai hơn | Phân tích |
|---|---|---|---|---|---|
| 1 | Tốc độ có doanh thu | | | | |
| 2 | An toàn tài chính | | | | |
| 3 | Tính đột phá | | | | |
| 4 | Giữ chân suốt vòng đời khách | | | | |
| 5 | Hào phòng thủ | | | | |
| 6 | Khớp ANCHOR / DNA | | | | |
| 7 | Khả năng nhân rộng | | | | |
| 8 | Chi phí triển khai ban đầu | | | | |
| 9 | Khớp năng lực hiện tại | | | | |
| 10 | Tác động đổi nhận thức thị trường | | | | |
| 11 | Rủi ro cạnh tranh | | | | |
| 12 | Câu chuyện cho nhà đầu tư | | | | |

Tổng điểm /60 và trung bình /5. Sau bảng điểm luôn có phần **"không phải chọn 1 bỏ 1"**:
- PA-A đang làm gì / PA-B bổ sung gì (bảng 2 cột).
- Điểm yếu chí tử nếu chỉ chọn A; nếu chỉ chọn B.
- **Phương án lai**: nguyên tắc ghép (một câu hình ảnh), lộ trình theo năm với từng mũi, % ngân sách, mục tiêu số.
- Dự phóng doanh thu: A riêng · B riêng · lai.
- **Nếu bắt buộc chọn 1**: bảng "chọn A khi… / chọn B khi…" theo 4 chiều tài chính, năng lực, tham vọng, khẩu vị rủi ro.

## 6. Cổng Go/No-Go

| Thời điểm | Số liệu cần xem | Đạt thì | Trượt thì |
|---|---|---|---|
| Q2 | Thí điểm A: bao nhiêu đơn/tuần | >500 đơn/tháng → tăng ngân sách lên 40% | <100 → giữ 20% |

Mỗi cổng có ngưỡng bằng số và hành động cho cả hai nhánh. Không viết "theo dõi và điều chỉnh".

## 7. Lộ trình

Theo quý hoặc theo năm, mỗi mốc có: việc, chân dung, kênh, KPI, người chịu trách nhiệm, ngân sách. Mốc nào thiếu người hoặc KPI thì máy kiểm loại `ke-hoach` của linhx-4d bắt.
