# 03 · Đối thủ và định vị

Rút từ `GTM_PART2_VN_POSITIONING` (Trân Bảo), `NC7_V1–V5 Cạnh tranh toàn diện`, phần khác biệt trong ANCHOR.

## 1. Bảng đối thủ (≥4 đối thủ thật + mình)

Cột là đối thủ, hàng là tiêu chí. Mỗi ô có số khi có thể, gắn `[BC]`.

| Tiêu chí | Đối thủ A | Đối thủ B | Đối thủ C | Đối thủ D | **Mình** |
|---|---|---|---|---|---|
| Định vị chính | | | | | (mục tiêu) |
| Số cửa hàng / kênh | | | | | |
| Thị trường mạnh | | | | | |
| Phân khúc sản phẩm chính | | | | | |
| Biên lợi nhuận | | | | | mục tiêu |
| Số hoá | | | | | |
| Văn hoá / di sản | | | | | |
| Chiến lược với người trẻ | | | | | |
| Thông điệp đang dùng (trích nguyên văn) | | | | | |

Thêm một bảng ngắn "DNA · phạm vi · di sản" cho 2 đối thủ gần nhất (mẫu trong ANCHOR Trân Bảo).

## 2. Bản đồ nhận thức 2 trục

Chọn 2 trục mà khách hàng thật sự dùng để phân biệt (không phải trục mình thích). Ví dụ đã dùng: **Tích trữ ↔ Thời trang/lối sống** × **Truyền thống ↔ Di sản văn hoá ↔ Hiện đại**. Đặt từng đối thủ lên, rồi khoanh góc trống.

```
           TÍCH TRỮ ←──────────────→ LỐI SỐNG
    A ■       │                    │   ■ D
    B ■       │   (KHOẢNG TRỐNG)   │
              │        ▲           │
              │       MÌNH         │
  ────────────┼────────┼───────────┤
  TRUYỀN THỐNG     DI SẢN        HIỆN ĐẠI
```
Dưới bản đồ, một câu in đậm: góc nào trống, ai đang giữ góc nào, mình chiếm góc nào và vì sao giữ được.

## 3. SWOT có hành động

- **Điểm mạnh / điểm yếu**: bảng 3 cột `# · điểm · giải thích hoặc giải pháp`. Điểm yếu nào cũng có giải pháp.
- **Cơ hội**: có cột **thời điểm** (bây giờ, 6–12 tháng, 12–24 tháng).
- **Thách thức**: có cột **xác suất %** và **cách giảm thiểu**. Ví dụ: "đối thủ lớn ra dòng tương tự trong 12–18 tháng · 60% · đi nhanh, câu chuyện sâu hơn".

## 4. Câu định vị (khung)

```
Cho [khách mục tiêu, tuổi],
những người [nhu cầu cụ thể],
<THƯƠNG HIỆU> là [hạng mục, "đầu tiên/duy nhất" nếu đúng],
biến [sản phẩm thành điều gì],
khác biệt vì [không làm X như mọi người, mà làm Y].
```
Kèm 3–5 câu khẩu hiệu thử, mỗi câu ghi giọng (sâu lắng, tự hào, gần gũi, táo bạo, mềm). Đề xuất một câu chính, một câu cho B2B.

## 5. Canvas đại dương xanh (Kim & Mauborgne)

Bảng yếu tố cạnh tranh × đối thủ, chấm ★0–5, cột cuối là **hành động**: LOẠI BỎ · GIẢM · NÂNG · TẠO MỚI.

| Yếu tố | A | B | C | D | **Mình** | Hành động |
|---|---|---|---|---|---|---|
| Bán theo gram | ★★★★★ | … | | | ★ | LOẠI BỎ |
| Số mã hàng | | | | | ★★ | GIẢM, ít mà chất |
| Câu chuyện văn hoá | ☆ | | | | ★★★★★ | NÂNG |
| Nghệ nhân có tên | ☆ | | | | ★★★★★ | TẠO MỚI |

Câu kết: mình bỏ gì, tạo mới những gì mà không đối thủ nào có.

## 6. Quy mô thị trường

TAM → SAM → SOM, mỗi tầng một dòng có công thức và nguồn. Kèm khung dự phóng doanh thu theo năm.

## 7. Kiểm trước khi chấm

- [ ] ≥4 đối thủ có tên, mỗi đối thủ ≥3 con số có nguồn
- [ ] Thông điệp đối thủ trích nguyên văn từ web, quảng cáo, bao bì
- [ ] Bản đồ 2 trục dùng trục của khách
- [ ] Thách thức có xác suất và cách giảm
- [ ] Canvas có ít nhất 1 LOẠI BỎ và 2 TẠO MỚI
- [ ] Mọi luận điểm về đối thủ có dòng trong bảng chứng thực (`06-chung-thuc.md`)
