# Rà soát kho

Skill này **không** viết kế hoạch ngày/tuần và **không** ghi vào `PLAN/` hay `D:\@WF\WIKI\`. Kế hoạch thuộc LINHX plan daily.

1. Đọc các file `00-INBOX/INBOX-*.md` chưa có mục "Đã xử lý" đầy đủ. Với mỗi dòng, đề xuất: EXP mới ở LAB / việc trong PRJ / note KB / lớp EDU / đưa vào plan daily / bỏ. **Hỏi Linh duyệt trước khi chuyển.**
2. Sau khi Linh duyệt: tạo note tương ứng (dùng `lab-moi` cho ý tưởng), rồi thêm dòng vào mục "Đã xử lý" cuối file INBOX.
3. Đọc `LAB/INDEX.md`, `PROTOTYPE/INDEX.md`, `LINHX-OPC/INDEX.md`: liệt kê EXP `IDEA` chưa thử, EXP `TESTING` quá 7 ngày, EXP `WORKS` chưa chấm cổng, PRT đang dựng/thử, OPC đang chạy.
4. Trả lời Linh bằng một bảng ngắn "đầu vào cho Weekly Planning": mục nào, trạng thái, việc tiếp theo đề xuất. Linh tự đưa vào kế hoạch tuần theo plan daily.
