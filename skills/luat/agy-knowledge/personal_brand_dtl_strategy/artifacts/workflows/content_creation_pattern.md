# Content Creation Workflow Pattern

This pattern is used to produce high-quality, data-driven content for the DTL brand.

## Phases

### 1. Multi-LENS Research (Researcher)
- **Goal**: Gather diverse perspectives (Scientific, Social, Personal).
- **Tooling**: Web search for latest data and internal guideline checks.
- **Output**: Structured Research Notes with cited sources.

### 2. Strategic Outlining (Planner)
- **Goal**: Determine the "Hook" and the narrative arc.
- **Tooling**: Outline creation with H1/H2/H3 structures based on the brand tone.
- **Output**: Content Outline.

### 3. Method-Acted Drafting (Writer)
- **Goal**: Embody the brand persona and draft the full text.
- **Tooling**: Reference `Brand_Voice.pdf` and the Agent Persona.
- **Output**: Draft v1.

## State Management
- **Artifacts Folder**: All intermediate files (Nodes, Outlines, Drafts) are stored in the task's `Artifacts/` directory.
- **Artifact Loop**: No phase can begin without the previous phase's artifact completion.
