# Bộ thử theo đích
Mỗi đích một file `thu/<loai>-<ten>.jsonl` (ví dụ `thu/skill-tra-ho-so.jsonl`), mỗi dòng một ca thật:
`{"id": "...", "dau_vao": "...", "phai_co": ["..."], "khong_duoc_co": ["..."], "nguon": "LX-0007"}`
Mỗi lỗi từng gặp thành một ca. Thăng cấp chỉ khi bản mới đạt hết và không kém bản cũ; người chấm khác thợ.
