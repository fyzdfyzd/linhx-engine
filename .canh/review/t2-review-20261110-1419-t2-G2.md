## Claude review
CHUA_DAT

- `apps/linhx_core/linhx_core/pay/api_ban.py:105-116`: `tao_don` is a public endpoint (`allow_guest`). Each time a customer places an order, it uses `frappe.db.set_value` to write `loai_giao="bao_cao"` into whatever `LX Goi` was ordered, skipping permission checks and swallowing errors. This hits the quyền and dữ liệu risk rows, and it rewrites the catalog: any non-report gói that someone orders gets routed into report delivery. Remove this block and set `loai_giao` through a seed or migration instead.
- `apps/linhx_goi_baocao/linhx_goi_baocao/sau_tra.py:609-612`: in the no-DB branch of `giao_bao_cao`, an order with `so_tien=None` gets the catalog `gia` or `gia_san` filled in. That bypasses the "đã trả nhưng thiếu số tiền → không tạo job" check in `viec_can_tao`/`gia_hop_le` (line 210), which is a money issue. Remove it: if `so_tien` is missing, return None and flag `can_xu_ly`, the same as `xu_ly_sau_tra` does.
- `apps/linhx_goi_baocao/linhx_goi_baocao/sau_tra.py:613-627`: that same no-DB branch returns a job dict (`name` "VIEC-…", `ma_xem` from `secrets.token_hex`, `link`) without saving anything. The caller sees "đã giao" while no `LX Job` exists, so the delivery is reported but never happened. Make this branch return None, or raise, and stop returning an unsaved job.
- `apps/linhx_goi_baocao/linhx_goi_baocao/sau_tra.py:436-453`: when the gói is not in the DB, `xu_ly_sau_tra` takes the `goi` dict passed in by the caller and uses it for `gia`/`gia_san`/`workflow`. It also fills fields that are empty in the DB from that dict (line 440). The minimum price is then checked against caller data instead of the catalog. Only the DB copy of `gia`/`gia_san` should be trusted, and no job should be created when the gói is not in the DB.
- `apps/linhx_core/linhx_core/pay/api_ban.py:15-31`: core pulls functions from the goi app while it is being imported (`_nap_ham_cung_cap` at module level). If `linhx_goi_baocao` is not installed, `api_ban` fails to import with `LookupError`, so core has a hard dependency on a goi-layer app, which is a reverse import in practice. Load the functions inside each endpoint and return a clear error when no provider is found.
